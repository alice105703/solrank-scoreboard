# 솔랭내기 점수판

롤 솔랭내기(2026.11.14 ~ 11.29) 점수판. 승/패 버튼을 누르면 연승·연패 보너스까지 자동 계산되고, 링크를 가진 사람 누구나 입력할 수 있다.

- `public/index.html` — 점수판 화면
- `api/state.js` — 점수 저장/불러오기 API (Vercel Blob 사용)
- 배포: Vercel (Blob 저장소 `solrank-scores` 연결 필요, `BLOB_READ_WRITE_TOKEN` 환경변수 자동 설정)

## 점수 규칙
- 승 +10, 패 -10
- 3연승째 판부터 +5씩 추가 (+15, +20, …), 3연패도 동일하게 차감
- 팀 점수는 총점 ÷ 팀 인원
